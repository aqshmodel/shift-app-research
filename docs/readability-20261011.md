## デプロイ手順の修正

初期の検証用コマンド `wrangler deploy --env staging` で、直前の本番ビルドの設定が優先され、本番へ先に反映されました。AstroのCloudflare Viteプラグインでは環境をビルド時に確定するため、公開前の対象確認が不足していました。本番での検査で表示の問題を特定・修正し、最終確認を完了しています。[Cloudflare公式の環境設定](https://developers.cloudflare.com/workers/vite-plugin/reference/cloudflare-environments/)

現在の `npm run deploy:staging` と `npm run deploy` は、対象環境でビルドした後、生成されたWorker名・環境変数・D1の接続先を原設定と照合します。合わない場合は反映前に停止します。解決済み設定へ環境名を二重適用しないようにし、Worker名も明示しています。二重適用で一時作成された未使用の検証Workerは削除しました。D1は削除・更新していません。
